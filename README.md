Resistor Combination Calculator

What it does

The Resistor Combination Calculator is a Python program that calculates the total resistance of resistors connected in series and parallel. It allows users to enter the number of resistors and their individual resistance values, then displays the calculated results.

How to run it

1. Install Python 3.
2. Open the project folder.
3. Run the following command:

"python resistor_calculator.py"

My own twist

I added input validation to prevent invalid entries from crashing the program. I also added an engineering insight feature that identifies the smallest resistor and explains the parallel resistance result.
